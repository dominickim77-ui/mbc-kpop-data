# LISA ‘SaWaDiKa’, 글로벌 차트에서 두 플랫폼 모두 하락

글로벌(Global) 기준 2026년 9월 25일~10월 1일과 2026년 10월 2일~10월 8일을 비교하면, LISA의 ‘SaWaDiKa’는 Spotify Charts에서 106위에서 152위로 46계단 하락했다. 같은 기간 주간 스트리밍은 9,627,318에서 8,704,202로 줄어 -9.59% 변했다. YouTube Charts의 Weekly Top Songs에서는 10위에서 17위로 7계단 내려갔고, 주간 조회수는 23,644,316에서 15,541,762로 -34.27% 감소했다. Spotify는 상위 200곡 차트, YouTube는 상위 100곡 차트로 범위가 다르며, 두 플랫폼의 수치는 서로 다른 지표다.

이번 초안은 제공된 분석 곡 1곡만을 다룬다. 순위와 변화율은 각 플랫폼 내부의 전주 대비 수치만 반영했으며, 서로 다른 단위인 스트리밍과 조회수를 합산하거나 비교해 해석하지 않았다. 출처: Spotify Charts, YouTube Charts. 검수 전 초안이며 최종 출고 미승인입니다.
